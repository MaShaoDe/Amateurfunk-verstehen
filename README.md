# Amateurfunk verstehen. Lernen für HB3 und HB9 (Schweiz)

Freies Lernmaterial für die schweizerischen Amateurfunkprüfungen **HB3** (Novice) und **HB9**.

Das Material führt Schritt für Schritt durch Mathematik-Vorkurs, Grundlagen, Technik, Betriebstechnik und Vorschriften. Es enthält Übungsreihen mit separaten Resultaten, Lernchecklisten und Merkblätter.

> Stand: im Aufbau. Eine erste Veröffentlichung folgt, sobald Struktur und Inhalt fertig sind.

## Aufbau

- `docs/`: alle Inhalte als Markdown
- `mkdocs.yml`: Navigation und Design (MkDocs mit Material-Theme)
- `LICENSES/`: Lizenztext

## Lokal ansehen

```
pip install -r requirements.txt
mkdocs serve
```

Die Seite ist dann unter http://127.0.0.1:8000 erreichbar. Mit `mkdocs build` entsteht der Ordner `site/` mit reinem HTML, den du auf jeden Webserver legen kannst.
