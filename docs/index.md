# Amateurfunk verstehen

**Lernen für die schweizerischen Prüfungen HB3 und HB9.** Schritt für Schritt, verständlich und frei nutzbar.

Wähle deinen Weg:

<div class="grid cards" markdown>

-   :material-radio-handheld:{ .lg .middle } **HB3 (Novice)**

    ---

    Der Einstieg. Du brauchst keine Vorkenntnisse in Elektronik. Kurze Lektionen, Übungen mit Resultaten und die Prüfungsthemen für die eingeschränkte Zulassung.

    [:octicons-arrow-right-24: Zum HB3-Kurs](hb3/index.md){ .md-button .md-button--primary }

-   :material-radio-tower:{ .lg .middle } **HB9**

    ---

    Die volle Zulassung (CEPT-Lizenz). Technik, Betrieb und Vorschriften in der ganzen Tiefe. Für Einsteigerinnen und Einsteiger genauso wie für alle, die von HB3 aufsteigen.

    [:octicons-arrow-right-24: Zum HB9-Kurs](hb9/index.md){ .md-button .md-button--primary }

-   :material-bookshelf:{ .lg .middle } **Allgemein**

    ---

    Gilt für beide Prüfungen: Übungsblätter, Frequenztabelle, Formelsammlung, Lernvideos und offizielle Stellen.

    [:octicons-arrow-right-24: Zum Allgemeinen Bereich](allgemein/index.md){ .md-button }

</div>
