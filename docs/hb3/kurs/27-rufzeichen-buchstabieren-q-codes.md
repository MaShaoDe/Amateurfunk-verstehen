# Lektion 27: Rufzeichen, Buchstabieren und Q-Codes

!!! abstract "Das lernst du in dieser Lektion"
    - Ein Rufzeichen zu verstehen
    - Das Buchstabieralphabet zu benutzen
    - Die wichtigsten Q-Codes und Abkürzungen zu kennen

*Dauer: etwa 30 Minuten. Voraussetzung: [Lektion 26](26-sicherheit-nis.md).*

## Das Rufzeichen

Das **Rufzeichen** identifiziert eine Funkstation eindeutig. Das BAKOM teilt es zu. Für Privatpersonen gibt es zwei Reihen:

- **HB3...** für die Stufe HB3 (Novice)
- **HB9...** für die Stufe HB9

Zum Beispiel HB3ABC: HB steht für die Schweiz, die Ziffer 3 für die Stufe, dahinter folgen Buchstaben. Wunschrufzeichen gibt es für Privatpersonen nicht, das BAKOM vergibt sie fortlaufend.

!!! note "Merksatz"
    Das Rufzeichen wird bei der Verbindungsaufnahme und danach **alle 10 Minuten** ausgesendet.

### Zusätze

Ein Zusatz nach dem Rufzeichen sagt, von wo gesendet wird:

| Zusatz | Bedeutung |
| --- | --- |
| /P | portable, anderer Standort |
| /M | mobil im Landfahrzeug oder auf dem Binnenschiff |
| /MM | maritime mobile, auf einem Seeschiff |
| /AM | aeronautical mobile, im Luftfahrzeug |

Der Zusatz wird mit einem Schrägstrich vom Rufzeichen getrennt, zum Beispiel HB3ABC/P. In Liechtenstein kommt für HB3 vor das Rufzeichen HB0Y/ (mit einer Null).

## Das Buchstabieralphabet

Bei schlechtem Empfang buchstabierst du Rufzeichen und Namen mit dem internationalen Buchstabieralphabet (ICAO, auch NATO-Alphabet genannt): Alfa, Bravo, Charlie, Delta und so weiter.

Das ganze Alphabet zum Üben findest du im [Übungsblatt Buchstabieralphabet](../../technik/uebungsblatt-buchstabieralphabet.md).

## Q-Codes

Q-Codes sind Kurzfragen und Kurzantworten, die in jeder Sprache gleich verstanden werden. Diese 14 Q-Codes solltest du für die Prüfung kennen (gilt für HB3 und HB9). Sie stammen aus dem Übungsblatt zur Kernliste und aus Kapitel 14 des HB9-Lehrwerks:

| Q-Code | Bedeutung |
| --- | --- |
| QRL | Ist die Frequenz belegt? Die Frequenz ist belegt |
| QRM | Ich werde gestört beziehungsweise meine Übermittlung wird gestört |
| QRN | atmosphärische Störungen beeinträchtigen den Empfang |
| QRO | Sendeleistung erhöhen |
| QRP | Sendeleistung vermindern |
| QRT | Übermittlung einstellen |
| QRV | Ich bin bereit |
| QRX | Ich werde Sie später beziehungsweise zu einer bestimmten Zeit wieder rufen |
| QRZ | Von wem werde ich gerufen? |
| QSB | Die Signalstärke schwankt |
| QSL | Empfangsbestätigung |
| QSO | Funkverbindung |
| QSY | auf eine andere Frequenz wechseln |
| QTH | Standort |

Merkhilfe: **QRM** kommt vom Menschen (andere Stationen, technische Störungen), **QRN** aus der Natur (Gewitter, atmosphärisch).

Alle Q-Codes für später stehen auf dem Blatt [Alle Q-Codes](../../technik/uebungsblatt-q-codes-alle.md). Zum Üben der Kernliste dient das [Übungsblatt Q-Codes für die Prüfung](../../technik/uebungsblatt-q-codes-pruefung.md).

## Weitere gebräuchliche Abkürzungen

| Kürzel | Bedeutung |
| --- | --- |
| CQ | allgemeiner Anruf an alle |
| 73 | beste Grüsse, auch Gesprächsschluss |
| DX | grosse Entfernung, ferne Station |
| OM | Funkamateur (englisch old man) |
| RST | Bewertung des Signals nach Lesbarkeit, Signalstärke und Tonqualität |
| UTC | einheitliche Weltzeit (Coordinated Universal Time) |
| YL | Funkamateurin (englisch young lady) |
| PSE | bitte (englisch please) |
| TNX | danke (englisch thanks) |

!!! tip "Prüfungstipp"
    Q-Codes und das Buchstabieralphabet musst du auswendig können. Übe sie regelmässig laut, am besten mit abgedeckter Antwortspalte.

## Mini-Übung

2. Was bedeutet der Zusatz /P?
3. Was bedeutet QRV?
4. Was ist der Unterschied zwischen QRM und QRN?
5. Wofür steht CQ?
6. Was bedeutet QRL?
7. Wofür stehen TNX und PSE?

## Das Wichtigste in 3 Sätzen

- Das Rufzeichen wird beim Anruf und alle 10 Minuten genannt.
- Das ICAO-Alphabet und die 14 Q-Codes musst du auswendig können.
- Zusätze wie /P und /M sagen, wo gesendet wird.
